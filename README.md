# Hashem Al Drous — Personal Site

A no-build static portfolio designed for GitHub Pages. Everything needed to publish it is in this folder.

## Publish free with GitHub Pages

### Option A — personal root site
1. Create a GitHub repository named **`<your-github-username>.github.io`**.
2. Upload **the contents of this folder** to the repository root (not the folder itself).
3. Commit to `main`.
4. Open **Settings → Pages**.
5. Under **Build and deployment**, choose **Deploy from a branch** → `main` → `/ (root)`.
6. GitHub will publish it at `https://<your-github-username>.github.io/`.

### Option B — any repository name
Use any public repository name, then enable Pages the same way. The URL will be `https://<your-github-username>.github.io/<repository-name>/`.

## Files
- `index.html` — site content
- `styles.css` — layout, typography, responsive design
- `script.js` — lightweight reveal animations
- `assets/hashem-portrait.webp` — optimized portrait
- `assets/Hashem-Al-Drous-Resume.pdf` — downloadable résumé
- `assets/favicon.svg` — browser icon

## Quick edits
All text is in `index.html`. Search for the section heading you want to change. The site has no framework, build command, analytics, or paid dependency.

## Design note
The visual direction is inspired by contemporary editorial AI/technology sites: warm paper tones, dark ink, restrained coral accents, large serif display type, and a strong grid. It does not use Anthropic logos or claim affiliation with Anthropic.
